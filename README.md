# Pet Adoption & Rescue Portal

## Project Overview

The Pet Adoption & Rescue Portal is a web-based application developed to help homeless and abandoned animals find loving homes. It provides an online platform for pet adoption, animal rescue reporting, and rescue status tracking.

## Objectives

- To simplify the pet adoption process.
- To help users report injured or abandoned animals.
- To provide rescue status tracking.
- To maintain adoption applications and rescue records.
- To provide an admin dashboard for managing requests.

## Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Development Tool:** Visual Studio Code
- **Version Control:** GitHub

## Main Features

1. Home page displaying available pets.
2. Online pet adoption application form.
3. Animal rescue reporting with photo upload.
4. Rescue status tracking using Rescue ID.
5. Contact Us form.
6. Admin login and dashboard.
7. Rescue status management.

## Conclusion

The Pet Adoption & Rescue Portal provides a digital solution for managing pet adoption applications and animal rescue reports. The system aims to improve communication, simplify record management, and promote animal welfare.
